Acoustic Analyzer

A local edge-AI that listens through a soldered microphone and explains what it hears — running entirely on an NVIDIA Jetson. No cloud, and no raw audio ever leaves the box: the language model reasons only over the numbers the DSP distills.

01

The trick: the model never hears raw audio

A 3-billion-parameter model can't listen to a waveform — and shouldn't have to. A Python DSP layer turns every recording into a compact set of structured facts, and the LLM reasons over those. That keeps the model small, the device offline, and the reasoning grounded in real measurements.

Hear

An electret mic + MAX9814 preamp you solder feeds clean audio to the Jetson over a USB sound card.

Distill

features.analyze() extracts dominant frequency, tonal peaks, band energy, a 60 Hz hum score, and a heuristic label — as JSON.

Explain

The local model calls that as a tool, then answers in plain language: “that's 60 Hz mains hum — likely a ground loop.”

Origin: a soldering project paired with a Jetson and a local LLM. It began as generic sensors, then pivoted to signal processing — where the GPU earns its keep and the soldering moves to a meaningful analog front-end.

06

Software & the plan ahead

The stack (all local, all free)

DSP — numpy · scipy · matplotlib · sounddevice
LLM — Ollama, GPU-accelerated on the Jetson
Model — qwen2.5:3b (strong tool-calling)
Chat — Open WebUI, browser, renders the spectrogram

Integration: one HTTP tool service

The decided next build is a thin FastAPI service over the existing tools — POST /analyze, POST /spectrum, plus an OpenAPI schema. Open WebUI calls it as an external tool server, and the same endpoint later powers the NFC trigger, the container deploy, and a possible Go/vakit vertical.

07

Future ideas

iPhone NFC reality: iPhones can read NDEF tags and trigger Shortcuts, but can't act as a programmable tag. So design around iPhone-as-reader + physical tags.

Tap-to-analyze ★

An NFC sticker on the enclosure + an iOS Shortcut that hits the Jetson's endpoint. Tap the phone → it records, analyzes, and speaks the result. No app — just the HTTP service.

PN532 reader on the Jetson ★

Solder a PN532 NFC module; physical tokens become commands — a “record” card, a “hum test” card, a “show spectrum” card. More real EE, over I²C.

Sound-reactive OLED

A soldered SSD1306 showing a live VU meter or spectrum right on the device.

Two-mic direction finding

TDOA / beamforming to point at a sound source — genuine multi-channel DSP.

“Shazam for household sounds”

The Stage-8 classifier naming appliances, alarms, and everyday noises.
